# Amrinder — Art-Directed Creative Portfolio

A custom static portfolio designed for GitHub Pages.

This edition intentionally moves away from a conventional card/grid portfolio toward an advertising/editorial experience:
- asymmetric art direction
- oversized typography
- campaign-specific visual worlds
- horizontal work strips
- sticky editorial sections
- subtle scroll choreography
- responsive mobile layout
- LinkedIn/Open Graph social preview preserved
