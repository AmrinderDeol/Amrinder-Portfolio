## Publish
1. Create a new **Public** repository on GitHub named `amrinder-singh-deol-portfolio`.
2. Upload the contents of this folder, keeping `README.md` at the repository root.
3. Confirm the resume opens from the `assets` folder.
4. Add approved portfolio images and case studies. Never publish confidential client files, internal Amazon/Walmart materials, customer data, proprietary metrics, or copyrighted assets you do not have permission to display.
5. Add the repository URL to LinkedIn, job applications, and your resume/portfolio site.

## Optional profile README
To show a portfolio introduction directly on your GitHub profile, create a public repository whose name exactly matches your GitHub username and place the contents of `PROFILE-README.md` into that repository as `README.md`.

## Before applying
- Replace generic case-study templates with 3–6 strong projects.
- Use compressed, high-quality visuals.
- Explain the business problem, your exact contribution, and verified results.
- Keep contact details current.
- Check every external link.
